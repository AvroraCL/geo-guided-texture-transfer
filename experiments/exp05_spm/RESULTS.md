# 实验 05 结果：简化代理映射（SPM）精度验证

**日期**：2026-10-16 ｜ **状态**：主链完成（阶段 6、7 待做）
**模型**：F16XL（本体 196,070 面，排除挂载物/起落架/轮子）
**脚本**：`make_proxy.py` → `project.py` → `resample.py` → `analyze.py`

---

## 一、一句话结论

**SPM 的图案转译误差平均 1.0 像素（按 2048 设计图折算），且约 98% 由「单张代理贴图的采样分辨率」造成——提高代理贴图分辨率即可直接压缩；几何简化 25% 几乎不增加错位（+0.02 px），其真正影响在「可见性判定」上。**

---

## 二、对照设计（三个配置）

| 配置 | M′ 的构成 | 目的 |
| --- | --- | --- |
| **校准（恒等）** | 不简化 + 保留原 UV | 验证测量链路本身（预期误差 ≈ 0） |
| **B：仅重排 UV** | 不简化 + 重新展开 UV | 分离「UV 重排」的贡献 |
| **主配置** | 25% 简化（49,017 面）+ 重新展开 UV | 测 SPM 整体精度 |

三者的基准路径相同：设计图（视图坐标编码场）经 top+left 两视图直接投影到 M 的 15 个材质空间。

## 三、三配置对比（核心数据）

| 指标 | 校准（恒等） | B：仅重排 UV | 主配置（25%+新UV） |
| --- | --- | --- | --- |
| 可比纹素 | 2,538,173 | 2,183,981 | 2,048,811 |
| **平均误差** | **0.001 px** | **0.979 px** | **1.001 px** |
| 内部纹素 | 0.000 px | 0.880 px | 0.880 px |
| 边界带纹素 | 0.017 px | 3.445 px | 4.433 px |
| 数值完全一致 | 78.5% | 10.5% | 0.4% |
| 视图选择不一致 | 209 | 63,147 | 108,383 |
| 仅基准有值（损失） | 1,115 | 292,369 | 382,303 |
| 仅 SPM 有值（增益） | 378 | 67,561 | 115,777 |

**读表要点**：

1. **校准行证明测量链路本身无系统误差**（0.001 px）——主配置测出的数值都是 SPM 真实引入的。
2. **B 行与主配置的「内部」完全相同（0.880 px）**——说明这部分误差与「几何简化」无关，纯粹来自「新 UV 布局下的采样」。
3. **简化的真实影响在右侧三行**（视图不一致 / 损失 / 增益约翻倍）——简化改变了几何的微小遮挡关系，导致可见性判定翻转，而**不是**导致图案错位。

## 五、误差归因（四类机制）

### 5.1 采样分辨率（主体，~88%）
- 代理贴图为单张 1024²（有值 17.9%），需供原模型 15 个材质空间的 480 万纹素采样（约 1:17）。
- UV 展开产生 12,153 个岛（平均每岛约 2.7 纹素）→ 双线性采样的 4 邻几乎必然跨岛 → 程序回退最近邻 → 采样误差约半纹素 ≈ **1.0-1.3 px**，与实测 0.88 px 吻合。
- **这不是原则性误差**：代理贴图分辨率翻倍，该项误差约减半。

### 5.2 UV 岛边界带（局部，~5 倍于内部）
- 边界带（1 像素宽）平均 **4.433 px**，内部 0.880 px。
- 机制：岛边界附近的采样容易读到 padding/邻岛值；双线性回退频繁。

### 5.3 薄壁与反向对应（少数，但幅度大）
- 按最近点法线与原始面法线的夹角分组：

| cos（法线夹角） | 纹素数 | 平均误差 |
| --- | --- | --- |
| > 0.9 | 2,028,280 | 0.937 px |
| 0.5–0.9 | 10,888 | 2.435 px |
| 0–0.5 | 4,032 | 6.069 px |
| **< 0（找到背向面）** | **5,611** | **17.809 px** |

- 少数（0.27%）纹素的最近点落在「朝向相反的面」上——即薄壁穿透或对应错层。这是**唯一由「对应方法」本身造成的误差类别**，其余都可由分辨率/采样修复。

### 5.4 视图选择不一致（非错位，但改变图案来源）
- 108,383 纹素（占可比 5.3%）在基准与 SPM 中选了不同视图（left↔top）。
- 集中在遮挡边界地带（典型：伞舱 `chute1_121`，其纹素的 24% 出现切换）。
- 影响：这些位置的图案内容来自不同视图，会破坏图案跨区域的延续性——**需要「视图一致性约束」**。

## 六、分部件表现

| 材质（部件） | 平均误差 | 特征 |
| --- | --- | --- |
| e0c5c4c8（机身主体大曲面） | **0.021 px** | 接近完美 |
| 1767095f（座舱/机身/尾部混合） | 0.131 px | 优秀 |
| 7e84b4a9（blister 鼓包） | 0.283 px | 良好 |
| f_16xl（机翼/尾翼/减速板等 125 个对象） | 1.279 px | 中等 |
| 7da99745（chute 伞舱） | 1.736 px | 视图切换多 |
| 9f26fb59（鼓包×3/座舱/座椅） | 2.636 px | 最差（小结构多） |

规律：**大面积平滑曲面 → 精度极高；小凸起、复杂小零件 → 误差升高**（与几何简化的局部影响一致）。

## 七、对 SPM 路线的评估

1. **可行性**：平均 1 px 级误差（且 78% 亚像素）**远低于「图案明显错位」的量级**。SPM 作为「中转映射」承载结构成立。
2. **主误差可工程解决**：提高代理贴图分辨率（1024→2048/4096）、改进跨岛采样——两者都不改变方法框架。
3. **真正需要方法改进的三处**：
   - 薄壁/近距双层结构的对应（现用朴素最近点，占误差极少数但幅度大）；
   - 视图选择一致性（约束重采样与基准同视图）；
   - 岛碎导致的 padding 敏感（可结合 `Robust Curve Embedding` 的接缝切分思路）。
4. **简化率的选择**：从本实验看，25% 简化对精度影响可忽略；简化率可以更激进（换取显存/速度）——但需在阶段 7 扫参验证（优先级已降低）。

## 八、复现指引

```bash
# 主配置（25%）
SPM_RATIO=0.25 blender --background --factory-startup --python make_proxy.py
SPM_MODE=base  blender --background --factory-startup --python project.py
SPM_MODE=proxy blender --background --factory-startup --python project.py
blender --background --factory-startup --python resample.py
python analyze.py

# 校准（恒等）
SPM_RATIO=1.0 SPM_SKIP_UV=1 SPM_KEEP_MAT=1 SPM_TAG=id100 blender ... make_proxy.py
SPM_MODE=proxy SPM_PROXY=proxy_id100.obj SPM_OUTSUB=proxy_id blender ... project.py
SPM_LABEL=id SPM_PROXY=proxy_id100.obj SPM_PROXYDIR=proxy_id SPM_OUTDIR=spm_id blender ... resample.py
SPM_LABEL=id SPM_SPMDIR=spm_id SPM_ANADIR=analysis_id python analyze.py
```

产物：`analysis_stats_{25,id,100uv}.json`、`analysis/error_<材质>.png`（绿=无误差、黄=视图不一致、灰=SPM 丢失、蓝=SPM 增益、红=大误差）。

## 九、局限

1. **面级可见性判定**（每面一次射线）——面边缘的部分遮挡未细分，会轻微放大「视图不一致」的计数。
2. **单位换算以 2048 设计图为基准**——误差的「像素数」随假设分辨率线性变化；物理单位换算为 ×18.578/2048。
3. **sample 的跨岛检测阈值为 0.05（视图空间）**——粗略但方向安全。
4. **误差仅衡量「坐标/位置」**，未衡量「图案内容」（如颜色、纹理细节）——坐标对齐是内容对齐的必要条件，但不是全部。
5. 阶段 6（棋盘格目视验证）与阶段 7（简化率扫描）未做。
