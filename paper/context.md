## 一、一句话定位

研究如何让 **AI 生成的多视图设计稿「无痛落地」**——在不修改既有 UV、不重新生成已有设计内容的前提下，把这些设计图准确映射到复杂三维模型表面，并处置跨视图、跨曲面与 UV 接缝处的问题。

**关注真实生产流程中的时间成本，而非生成纹理的视觉美观。**

## 二、背景

来源是游戏外观模改（skin／涂装）的实际生产。真实流程为：

```
Blender 整理模型并渲染正交视图（飞机通常只需顶视图 + 左视图）
  → Photoshop 依正交视图绘制平面设计稿
  → Substance Painter 中做立体映射、对齐、画遮罩、处理材质
  → 导入游戏验证、迭代
```

其中抠图、素材生成、参考图生成已由 AI 承担。**断层在于**：图像模型能产出设计参考，大语言模型能转译需求，但二者都无法完成从**外观分布**到 **UV 空间对应**的转换——参考图上"长这样"的图案，究竟对应模型表面哪一位置、跨过 UV 接缝后如何接续。

本文称这一缺失环节为**中间层**。

**成本参照**（由从业者提供，累计完成 200 余项涂装）：从获取三视图、绘制定位标记到在纹理软件中对齐，约 **10–20 分钟**；绘制遮罩约 **10–30 分钟**。

## 三、目标与非目标

**目标**

1. 把该工程断层界定为可研究的问题，并给出形式化描述；
2. 给出硬约束清单与输入输出契约；
3. 梳理设计空间，列出候选路线并分析取舍；
4. 设计验证方案，**并已完成其中两项的执行**（见第七节）。

**非目标（明确排除）**

- 不提出新的生成模型，不声称改进任何现有算法；
- 不研究"生成好看的新纹理"——本文处理的是**既有设计稿的精确转译**；
- 不修改既有 UV 布局（见约束 C1）；
- 不引入缺乏必要性的深度模型；
- 不追求"一步到位"的全自动，判据是**每次能省多少时间**。

## 四、生产约束（C1–C6）

来源：单一从业者的实践归纳，**尚待更多从业者交叉验证**（`[假设]`）。

| 编号 | 约束 | 含义 | 排除效果 |
| --- | --- | --- | --- |
| C1 | UV 不可重排 | 数十万面量级 UV 一旦重排，牵连法线烘焙、LOD 与平台规范 | 排除"重新参数化为整块"路线（但见路线 D） |
| C2 | 规模 | 面数达数十万，逐面人工介入不可行 | 要求全流程自动 |
| C3 | 规范 | 贴图尺寸、通道、命名与格式由平台规定 | 输出须可被规范校验 |
| C4 | 可编辑 | 结果须交回美术继续修改 | 排除不可回改的黑箱方案 |
| C5 | 接缝不可见 | 跨接缝处不得出现可见断裂、错位或拉伸突变 | 接缝处理是一等公民 |
| C6 | 无空洞 | 未覆盖表面须有合理延续 | 必须具备推演机制 |

## 五、核心概念

### 三种空间，三种邻接（**不得混为一谈**）

| 类型 | 含义 | 性质 |
| --- | --- | --- |
| 三维表面拓扑邻接 | 网格上共享一条边 | **唯一确定的几何事实** |
| UV 参数化空间邻接 | 贴图上相邻的纹素 | 取决于 UV 如何展开；同一条三维边可能被切开 |
| 正交投影图像邻接 | 设计稿上相邻的像素 | 取决于投影方向与遮挡；最弱的一种 |

三者关系：**三维邻接是事实，另两者是它在不同参数化下的像，且都不是单射。**

**关键澄清：UV 岛在纹理空间中不连续，并不意味着对应的三维表面关系不可计算。** 跨 UV 岛的关系完全可以、也应当由几何算法直接算出（沿表面度量距离即是手段）。把两者混淆会导致错误结论——以为跨接缝的图案连续性"无法求解"。

### 测地距离

沿表面度量、而非穿过空气的距离。判断"谁跟谁真的挨着"只能靠它。网格上的成熟算法：快速行进法 [Kimmel & Sethian 1998]、热方法 [Crane et al. 2013]。

### 接缝的三种类型

| 类型 | 来源 | 可解性 |
| --- | --- | --- |
| **UV Seam** | 参数化人为切开 | **确定性可解** |
| **Geometry Seam** | 建模方式（多网格块、非流形） | 需先分：位置重合→可解；实际分离→不存在待延续关系 |
| **Projection Seam** | 三来源：内容冲突／可见性切换／信息缺失 | **输入冲突只能优化取舍；信息缺失只能推演** |

**区分准则：凡属"表示"造成的不连续，应由确定性算法解决；凡属"输入冲突或缺失"造成的，才需要优化或推演。**

### 需要保持的设计边界 vs 需要消除的伪接缝

设计稿本身含**有意为之的边界**（分色线、图案轮廓、水贴边缘），不得消除；需消除的是**伪接缝**（参数化／投影引入的）。两者在像素层面都是"颜色跳变"，**目前无法自动区分**——这是一个未解决问题。

## 六、三个子问题（含实验后的修正）

1. **对应**：设计稿图案元素落在 UV 的哪一位置。
   **已证明为纯几何问题**：投影函数连续，跨接缝两侧对应同一三维点时投影值必然相同，不存在误差（见第七节 A1）。
2. **延续**：多视图未覆盖的表面，图案如何延伸。**推演问题，本文认定的核心难点。** 但据从业者经验，"三视图看不到的地方玩家也未必看得到，手工处理即可"，其真实规模尚待细分。
3. **合规**：结果是否满足尺寸、通道、接缝与可编辑性要求。

## 七、已完成的实验与结论 ★

截至 2026-10-16，共完成四项实验。全部脚本与数据见仓库 `experiments/`，可复现。

| 编号 | 内容 | 结论 |
| --- | --- | --- |
| exp00 | 素材诊断 | 测试模型 343,843 三角面、10,616 个 UV 岛、76,234 条真 UV 接缝 |
| exp01 | 基准正交视图 | 产出 6 张视图与相机参数 |
| **exp02** | **三视图覆盖率（对应 A2）** | **未覆盖率 19.61%**，A2 假设成立 |
| **exp03** | **跨 UV 接缝误差（对应 A1）** | **投影无误差**；A1 原命题被否证 |
| exp04 | 判定方法可靠性 | 重叠几何 0.08%（无问题）；法线虽已修正但未能独立交叉验证 |

**由此产生的两项方向修正**：

1. **跨接缝连续性不是问题**。既然投影不产生误差，原假设 H1（几何约束降低跨缝跳变）失去检验对象，已标注失效。
2. **研究重心收敛到「未覆盖区域的补全是否可行」**。这是当前唯一的核心假设。

## 九、四条候选路线

| 路线 | 做法 | 状态 |
| --- | --- | --- |
| **A** | 投影锚定 + 测地补全 | — |
| **B** | UV 空间直接生成 | — |
| **C** | 混合（投影锚定 + UV 空间补全） | 当前推荐，尚未验证 |
| **D** | **简化代理映射（Simplified Proxy Mapping, SPM）** | 2026-10-16 提出，**尚未验证** |

**路线 D 要点**：把原模型重新拓扑为简化模型（**代理网格**），在代理网格上完成映射，再重采样回原模型的原 UV。约束 C1 管的是"原模型 UV 不得改动"，本路线从未改动原模型，故不与 C1 冲突——这是它与 UniTex 重新参数化原模型的根本区别。

**其风险**：对应关系需额外计算（薄壁并层、凹陷变浅、自遮挡处可能求错）；两次采样的精度损失；代理网格自身仍需切割。

## 十、术语速查

| 常用说法 | 术语 |
| --- | --- |
| 把三维表面摊平成平面的坐标 | UV 参数化 |
| 摊平后的一块连通区域 | UV 岛 / chart |
| 因必须剪开而形成的边界 | 接缝 / seam |
| 沿表面走出来的距离 | 测地距离 / geodesic distance |
| 把参考图作为条件喂给生成模型 | 条件注入 / conditioning |
| 外观对了但位置对不上 | 外观分布与空间对应的分离 |
| 借一个简化模型中转做映射 | 简化代理映射 / Simplified Proxy Mapping (SPM) |
| 中转用的简化模型 | 代理网格 / proxy mesh |
