## 二、设计逻辑：闭环对照

```
            ┌─ 基准路径：设计图 ──直接投影到 M──→ 基准贴图
设计图 ─────┤      （A1 已证明投影本身无原理误差）
            └─ SPM 路径：设计图 ──投影到 M′──→ M′ 贴图 ──重采样──→ SPM 贴图
```

**误差 = |SPM 贴图 − 基准贴图|**，逐纹素统计。

两条路径共用同一套相机参数与同一张设计图，唯一差别是 SPM 路径多了
「经 M′ 中转」这一环。因此任何差异都归因于 SPM 的两个新增环节：

1. **几何近似** —— M′ 简化后与 M 形状不一致；
2. **重采样** —— 纹素到纹素的插值与对应。

这两个因素可以进一步分离：
- 重采样时同时记录「M 上的点到 M′ 的距离」，该距离是几何近似的直接度量；
- 若某处距离小但误差大 → 说明是**对应找错了**（薄壁/凹陷问题），
  而非几何偏差本身。这正是区分「误差由简化造成」与「误差由对应方法造成」的判据。

## 三、关键设定与理由

| 项目 | 设定 | 理由 |
| --- | --- | --- |
| 视图 | **顶视图 + 左视图（两张）** | CL 实际工作只用这两张；此前 A2/A1 用了三视图，与真实场景不符，本实验纠正 |
| 设计图 | **视图坐标编码场**（R=视图u, G=视图v, B=视图编号） | 每个纹素的颜色即是它的理论坐标 → 误差可精确量化，无需真实设计稿；色调连续故另配棋盘格版做目视检查 |
| 误差单位 | 视图坐标差 × 2048 | 换算成「设计图上错位几个像素」，对画师直观 |
| 贴图分辨率 | 1024（跑通后再升 2048） | 控制首轮运行时间 |
| 对应方法 | BVH 最近点（最朴素基线） | 先暴露问题，再谈改进 |
| 统计范围 | 仅飞机本体（排除挂载物/起落架） | 与 A2 口径一致（CL：挂载物套原游戏贴图） |

## 五、主配置结果（25%）与三配置对比

| 指标 | 校准（恒等） | B：仅重排 UV | 主配置（25%+新UV） |
| --- | --- | --- | --- |
| 平均误差 | 0.001 px | 0.979 px | **1.001 px** |
| 内部纹素 | 0.000 px | 0.880 px | 0.880 px |
| 边界带 | 0.017 px | 3.445 px | 4.433 px |
| 视图不一致 | 209 | 63,147 | 108,383 |
| 仅基准有值 | 1,115 | 292,369 | 382,303 |

**关键判读**：误差主体来自「新 UV 布局下单张 1024² 代理贴图的采样分辨率」（B 与主配置的内部误差完全相同），而非几何简化。详见 `RESULTS.md`。

## 六、预判的失败模式

| 观察到的现象 | 解释 | 对论文的意义 |
| --- | --- | --- |
| 误差集中于薄壁/凹陷，且与最近点距离弱相关 | 对应方法（最近点）在薄壁处找错点 | 论文预测成立 → SPM 需要更稳的对应方法 |
| 误差与最近点距离强相关、处处均匀 | 误差主要来自几何简化本身 | 提高简化率即可缓解 → SPM 可行 |
| 误差普遍极小（<1 像素） | 朴素方法已够用 | SPM 风险被高估 → 可直接作为阶段零工具的技术路线 |
| 大量纹素「视图选择不一致」 | M 与 M′ 可见性不同的点选了不同视图 | 需在重采样中引入视图一致性约束 |
