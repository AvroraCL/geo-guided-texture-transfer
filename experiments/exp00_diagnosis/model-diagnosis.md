### 两点澄清

**1. UV 总面积 13.84 不是重叠，是 15 个材质各占独立 UV 空间。**
每个材质的 UV 面积都在 0.6–2.0 之间，累加得 13.84。这是"每材质一张贴图"的标准做法。**因此 A2 的覆盖率必须按材质分别统计，不能合并。**

**2. 机身 UV 的负值不是多图块排布。**
f_16xl 的 UV 引用共 561,231 个，其中 99.97% 落在 v ∈ [0,1)；落在 v < 0 的仅 189 个引用（约 63 个面）。这是零星瑕疵，不是图块排布。同样，材质 `1767095f…` 有 146 个面越界。两处合计 209 面，占 0.06%，可在采样时单独剔除。

## 四、对 A1／A2 的判断

| 判断 | 依据 |
| --- | --- |
| **适合做 A1 样本** | 76,234 条真接缝边，38.9% 的面涉及接缝，问题规模充分，不存在"问题太小测不出来"的风险 |
| **A2 必须分材质统计** | 15 个材质独立 UV 空间，覆盖率与未覆盖分布都要出 15 份 |
| **采样需排除边界边** | 44,780 条单面边与 139 条非流形边不构成跨接缝对 |
| **UV 越界可局部剔除** | 209 个面，占 0.06% |

## 五、未决问题（需作者确认）

1. **该 UV 布局是人工整理过的，还是游戏原始导出？**
   机身 5,141 个岛（平均每岛 36 面），对人工整理的 UV 而言偏碎。若这是游戏原始状态，则本样本具代表性；若作者日常面对的是整理过的 UV，则本样本偏极端，需另找对照样本。
2. **设计稿来源？**
   是 Blender 渲染正交视图后绘制（有配准），还是 AI 生成（无配准）？这决定 A1 能否直接进行。
3. **模型单位与朝向？**
   包围盒 y 向 31.77，对 F-16XL（机长 16.5 m）而言偏大，疑含外挂或单位非米。相机参数需据此设定。
