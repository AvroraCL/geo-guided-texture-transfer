# 实验 02：三视图覆盖率（A2）

> OrthoTex 开放研究项目 ｜ 日期：2026-10-16 ｜ 状态：**已完成**
> 对应假设：A2（未覆盖区域的实际规模）

---

## 一、实验目的

测量「正、侧、顶」三个正交视图对飞机表面的覆盖情况，回答：

> **设计师用三个视图做涂装时，有多少表面是没有任何设计稿信息的？**

这个数字决定论文中「延续」问题是否真实存在。按 `research/hypotheses.md`，**A2 的否证条件是"占比很小（如 < 5%）"**。

## 二、方法

**判定方式：射线遮挡检测**，不是"UV 上有没有颜色"。

对每个三角面：
1. 面法线背对相机 → 不可见
2. 法线朝向相机 → 从面中心沿视线投射射线，**第一个交点必须是该面自身**才算可见
3. 被三个视图中任意一个看到 → 计为「已覆盖」

**统计范围**：飞机本体（机身、机翼、尾翼、座舱等）。
**排除**：武器、挂载、副油箱、起落架——作者说明这些部件在实际涂装中**套用原游戏贴图，不做设计**。

## 三、结果

| 指标 | 数值 |
| --- | --- |
| 参与计算的面数 | 216,694 |
| 覆盖率（按面积加权） | **80.39%** |
| **未覆盖率** | **19.61%** |
| 未覆盖（按面数） | 50,289 ／ 216,694（23.2%） |

**三个视图各自的可见比例**：front 38.8% ／ right 39.3% ／ top 43.1%（三者有重叠，非简单相加）

**按部件（含挂载物时的对照）**：

| 部件 | 未覆盖比例 |
| --- | --- |
| 挂架 | 33.1% |
| AIM-9 发射架 | 30.7% |
| AIM-9L / AIM-120 导弹 | 25.0% |
| 机身 | 22.9% |
| 副油箱 | 15.7% |

**含全部部件与仅本体的对比**：20.57% ／ 19.61% —— 相差仅约 1%，说明范围界定对结论影响很小。

## 四、与假设的对照

> A2 假设：未覆盖区域在真实模型上占比显著。
> 否证条件：占比很小（如 < 5%）→「延续」难点被高估。

**实测 19.61%，远高于 5%。结论：A2 假设成立。**

未覆盖区域确实存在且规模不小——**约五分之一的表面没有设计稿可参照**。

## 五、过程中的三次错误（记录下来，供后续参考）

本研究首次实验，测量方法经过三版修正。三次错误都出在判定逻辑，而非数据本身：

| 版本 | 未覆盖率 | 错误原因 |
| --- | --- | --- |
| v1（GUI 版） | 32.9% | 模型有 **36 个对象的法线朝内**（轮子、减速板、部分起落架、尾喷口）。这些对象被整体误判为未覆盖 → **偏高** |
| v2（双向起点） | 0.15% | 为兼容反法线而加了「双向尝试起点」，结果 `sign=-1` 时从面内侧出发，射线立刻击中该面自身，**所有背向相机的面都被判为可见** → **偏低** |
| **v3（修正法线）** | **19.61%** | 先用有符号体积检测并翻转 36 个反法线对象，再执行标准判定 → **正确** |

**教训**：

1. 覆盖判定不应依赖法线朝向；遇到反法线的模型，**先修法线**再判定，而不是在判定逻辑里打补丁。
2. 该模型 15 个材质各占独立 UV 空间，画 UV 热图时必须**按材质分开输出**，否则会互相覆盖。
3. 「看不到了」的原因需要逐层排除：模型问题（法线）、脚本问题（逻辑）、真实情况（几何遮挡），三者不能混为一谈。

## 六、一个真实现象

挂载物（导弹、副油箱）在三个标准正交视图中几乎完全不可见——它们挂在机翼下方，从上方被机翼挡住、从侧面被机身挡住、从前方被机身挡住。**这不是 bug，是几何事实**，也印证了本文讨论的信息缺口。

## 七、产出物

| 文件 | 内容 |
| --- | --- |
| `run_cli_bodyonly.py` | **主脚本**：仅本体的覆盖率计算（含法线修正） |
| `run_cli.py` | 全量版本（含挂载物与起落架），用于对照 |
| `make_heatmap_cli.py` | 生成 UV 空间热图 |
| `coverage_bodyonly.json` | **最终数据**：逐面覆盖计数 |
| `heat/` | 各材质的 UV 热图（灰色=有参考，红色=无参考） |
| `_archive/` | 过时脚本与失败产物（保留以备复查） |

**运行方式**：

```bash
blender --background --factory-startup --python run_cli_bodyonly.py
```

## 八、可复现性

- 模型：`F16XL.obj`（作者提供，34.4 万三角面）
- 环境：Blender 5.1.2
- 脚本自行完成导入 → 法线修正 → 射线检测 → 统计，**不依赖任何手工操作**
- 首次运行约 15 秒（不含导入）
