# 实验 04：判定方法的可靠性检查

**目的**：CL 提出疑虑——不能确定模型是否真的修好；三角面重叠与面朝向问题有时并不影响映射。

## 结果

### ✅ 重叠几何：无问题
| 项目 | 数值 |
| --- | --- |
| 顶点总数 | 125,882 |
| 唯一位置数 | 125,777 |
| 重合位置 | **105（0.08%）** |

重合多源于 UV 接缝、材质边界、硬边的正常顶点拆分。**不存在会干扰射线判定的重叠面。**

### ❌ 独立验证覆盖率：三次均失败
| 脚本 | 方法 | 结果 | 失败原因 |
| --- | --- | --- | --- |
| `verify.py`（初版） | 起点沿射线反方向后退 | 99.82% | 方向写反，背向面被误判为可见 |
| `verify.py`（修正） | 从面朝相机方向判遮挡 | 48.48% | 判据过严，正常面也被判为被遮 |
| `verify2.py` | 相机逐像素发射射线 | 34.41% | 采样不足：78 万条射线仅覆盖 1–2 万个面 |

**结论**：从"面"出发的射线对起点位置极度敏感；相机射线法测的是屏幕空间覆盖，与面积加权的表面覆盖率不是同一指标。

**exp02 的 80.39% / 19.61% 仍是目前最可信的数字**，但依赖法线修正，该局限已写入论文 5.2.5 节与第 6 章。
