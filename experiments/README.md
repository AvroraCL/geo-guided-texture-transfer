| 假设 | 内容 | 状态 |
| --- | --- | --- |

**重要转向**：A1 的结果把研究重心从「跨缝连续性」移到了「未覆盖区域的延续」。A3 需要重新定义。

## 运行方式

所有脚本支持命令行运行，**不需要在 Blender 界面里操作**：

```bash
# 覆盖率计算（仅飞机本体）
blender --background --factory-startup --python experiments/exp02_coverage/run_cli_bodyonly.py

# 生成 UV 空间热图
blender --background --factory-startup --python experiments/exp02_coverage/make_heatmap_cli.py
```

`--factory-startup` 用于跳过第三方插件，避免报错信息干扰输出。

## 已知的模型问题

1. **36 个对象的法线朝内**（轮子、减速板、部分起落架、尾喷口）。
   脚本已在计算前自动检测并翻转（依据有符号体积）。原始 `F16XL.obj` 未修改。
2. **15 个材质各占独立 0–1 UV 空间**，UV 热图必须按材质分开输出。
3. **23 个 `vehicle#gear_c*` 零件位于 y ≈ −28**，远离飞机主体。计算包围盒与相机参数时需排除（`exp01` 脚本已自动处理）。
