# OrthoTex 实验记录

> 更新：2026-10-16 ｜ 环境：Blender 5.1.2 ｜ 模型：`F16XL.obj`（34.4 万三角面）

本目录记录 OrthoTex 项目的**实际实验**。每项实验的脚本、数据与结论都在各自子目录中，可复现。

**原则**：只记录真实执行过的结果。失败与错误同样记录（见各实验的「错误记录」），不删改。

## 对应研究假设

| 假设 | 内容 | 状态 |
| --- | --- | --- |
| A2 | 未覆盖区域占比显著 | ✅ **已验证**：19.61%（否证条件为 < 5%） |
| A1 | 纯投影产生可测量的跨缝跳变 | ❌ **被否证**：投影在跨接缝处不产生误差（数学必然）。真正的问题是可见性缺口 |
| A3 | 几何约束降低跨缝跳变 | ⚠️ **命题失效**：既然跨缝跳变不存在，原命题不成立。问题已转向「信息缺失的补全质量」 |
| H-D1 | 代理网格与原模型的对应可达足够精度 | ✅ **已验证**：99.7% 样本工作良好；0.27% 出现「找错层」（薄壁/反向法线） |
| H-D2 | 两次采样中转精度损失可接受 | ✅ **已验证**：0.98–1.0 px（2048 设计图），且与简化率基本无关 |

**重要转向**：A1 的结果把研究重心从「跨缝连续性」移到了「未覆盖区域的延续」。A3 需要重新定义。

## 运行方式

所有脚本支持命令行运行，**不需要在 Blender 界面里操作**：

```bash
# 覆盖率计算（仅飞机本体）
blender --background --factory-startup --python experiments/exp02_coverage/run_cli_bodyonly.py

# 生成 UV 空间热图
blender --background --factory-startup --python experiments/exp02_coverage/make_heatmap_cli.py
```

`--factory-startup` 用于跳过第三方插件，避免报错信息干扰输出。

## 已知的模型问题

1. **36 个对象的法线朝内**（轮子、减速板、部分起落架、尾喷口）。
   脚本已在计算前自动检测并翻转（依据有符号体积）。原始 `F16XL.obj` 未修改。
2. **15 个材质各占独立 0–1 UV 空间**，UV 热图与投影贴图必须按材质分开输出。
3. **离群零件**：23 个 `vehicle#gear_c*` 与 3 个 `wheel_*` 位于装配前坐标（远离飞机主体），
   计算包围盒与相机参数时必须排除（排除键：`gear_`、`wheel_`）。
   **exp01 的自动排除规则当时还误伤了机头段对象**，导致俯视图纵向被裁切；
   exp05 改为按部件名显式排除，得到正确包围盒（9.964 × 17.693 × 4.463）。
