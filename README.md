# 基于几何约束的多视图二维设计向复杂三维模型表面的高保真纹理转译技术

> 问题定义与方案设计　｜　草案 v0.5

作者：**AvroraCL**

## 这是什么的

本文讨论游戏外观模改（skin / 涂装）生产中的一个工程断层：把多视图二维设计稿转译成复杂三维模型表面可用的 PBR 贴图，至今仍高度依赖人工。

图像生成模型与大语言模型已经能覆盖首尾两端——出设计参考、转译需求——但补不上中间那一环：参考图上"长这样"的图案，究竟对应模型表面哪一位置，跨过 UV 接缝之后又该如何接续。

本文做的四件事：把该断层界定为一个可研究的问题；给出它的六条硬约束；梳理由此决定的设计空间；给出可执行的落地分工与尚未执行的验证方案。

**本文不提出新的生成模型，也不声称已有实现。** 面向熟悉 PBR 流程、不熟悉图形算法与人工智能的美术从业者写作。
